Візуалізація теореми Кантора про перетин множин. Шишкіна Аліса АМ29
Інтерактивний вебзастосунок для наочної покрокової візуалізації теореми Кантора 
в метричному та евклідівому просторах.
Метричний простір був розглянут на базі lecture notes 9-10
Евклідовий простір був розглянут на базі відео RB Maths Academy (https://www.youtube.com/watch?v=ZdV_aJMGKZM)

Використано:
HTML5 / SVG - структура сторінки та векторні графічні примітиви.
CSS3 - стилі, адаптивна розмітка(Flexbox/Grid), переходи.
JavaScript (ES6+) - логіка перемикання кроків, маніпуляція DOM/SVG, обробка подій клавіатури й інтерфейсу.
KaTeX (CDN) - бібліотека для рендерингу математичних формул у вебсередовищі( компілятор синтаксису LaTeX у HTML/MathML).

Використання ШІ: 
Штучний інтелект залучався суто як консультаційний інструмент для:
-вибору бібліотеки відображення формул (рекомендація KaTeX);
-пошуку та усунення технічних багів (екранування символів у формулах, конфлікти обробки клавіатурних подій);
-допомога в реалізації коректної графічної репрезентації
